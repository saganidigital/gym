# IRONPULSE ELITE // Hyper-Performance Athletic Club

An ultra-modern, high-intensity front-end web application built for gym lovers, powerlifters, and high-performance athletes. Engineered with vanilla HTML5, CSS3, and JavaScript, featuring a dynamic Biomechanical HUD hero page, interactive training protocols, macro calculator, facility showcase, and Gemini AI-generated visual assets.

---

## ⚡ Features

- **Biomechanical HUD Hero**:
  - Interactive Training Protocol Switcher (`[01] HYPERTROPHY // PUMP`, `[02] POWERLIFTING // LOAD`, `[03] BIO-RECOVERY // CRYO`).
  - Interactive HTML5 Canvas particle system simulating floating chalk dust and glowing red embers.
  - 3D layered depth typography positioned behind the athlete visual.
  - "Ignite Neural Drive" adrenaline trigger with synthesized 808-style audio pulse and screen vibration.
- **Biometric & Macro Target Calculator**:
  - Mifflin-St Jeor equation engine computing BMR, TDEE, and exact Protein/Carb/Fat macro breakdowns based on fitness goals (*Aggressive Cut*, *Lean Recomp*, *Clean Bulk*).
- **Interactive Facility Showcase**:
  - Real-time tab switcher for *The Iron Vault*, *Velocity Turf & Cardio*, and *Cryo & Bio-Recovery* featuring Gemini-generated photography.
- **Filterable Programs Explorer**:
  - Filter by *Hypertrophy*, *Strength & Power*, and *Metabolic Conditioning*.
- **Membership Matrix**:
  - Monthly vs. Annual toggle with a 20% savings calculation.
- **Synthesized Web Audio UI Feedback**:
  - Native Web Audio API sound synthesizer with FX ON / FX OFF toggle.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)

### Run Locally
```bash
node server.js
```
Then navigate to `http://localhost:3000` in your web browser.
